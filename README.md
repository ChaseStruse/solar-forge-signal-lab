# Solar Forge Signal Lab

A native audiovisual playground for creating immersive spaceship soundscapes.
Mix reactor hum, rain against the cockpit, radio static, and passing ships into
your own ambient scenes.

## Initial direction

- Layer sounds with independent volume controls.
- Bring each soundscape to life with an animated visualization.
- Save and revisit favorite scenes.

This repository is initialized; application development takes place on the `Init`
branch. The first prototype will focus on three sound layers, volume controls,
and one animated scene.
